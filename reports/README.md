# EC2 Audit Reports

This directory stores reports generated by the Python/Boto3 EC2 auditing script.

## Report Files

### 1. CSV Report

`ec2_audit_report.csv`

Contains EC2 audit records in CSV format. It can be opened with spreadsheet applications such as Microsoft Excel.

### 2. JSON Report

`ec2_audit_report.json`

Contains EC2 audit records in structured JSON format for further processing.

## Report Information

Each instance record can contain:

- Instance ID
- Instance Type
- State
- Name
- Owner
- Audit Time
- Launch Time
- Estimated Monthly Cost

## Generating Reports

Run the auditor from the project root:

```bash
python scripts/aws_audit.py
```

The script automatically creates this directory if it does not exist and exports both report formats when EC2 records are found.

## Git Tracking

Generated CSV and JSON reports are excluded from Git to avoid committing changing audit data.

This README is tracked by Git and explains the purpose of the directory.
